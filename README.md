# Справочник противопожарных клапанов

Где предусматривать нормально открытые и нормально закрытые клапаны, клапаны двойного действия и огнезащиту воздуховодов. Каждая запись ссылается на пункт нормы.

Сайт: https://magichvac.github.io/klapany/

## Как дополнять

- Новый случай: добавить запись в `js/data_no.js`, `js/data_nz.js` или `js/data_more.js`. Формат описан в шапке файла.
- Новая норма: добавить объект в `NORMS` в `js/data_norms.js`.
- Новая схема: добавить описание в `js/schemes.js`, движок дорабатывать не нужно.
- Версия: `APP.ver` и `NEWS` в `js/data_norms.js`, `?v=` в `index.html`, `V` и `FILES` в `sw.js`.

Справочник не заменяет тексты норм. Перед выпуском проекта сверяй действующую редакцию.
